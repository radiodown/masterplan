# 포레스트 플랜

아이파크 포레스트 84B의 납부 일정과 보유자산을 기준으로 입주 자금을 계산하는 로컬 웹 앱입니다. 프런트엔드는 React와 Vite, 백엔드는 Node.js와 Express로 작성했습니다.

개요의 게이지는 전체 필요 금액을 이미 납부한 돈, 입주까지 마련할 자기자금, 추가로 필요한 금액으로 나눠 보여 줍니다. 아래에서 월 저축액, 보유자산, 조기상환 계획을 바꾸면 게이지가 바로 갱신됩니다.

## 실행

Node.js 22 이상에서 다음 명령을 실행하고 [로컬 웹 앱](http://127.0.0.1:5173)을 엽니다.

```powershell
npm ci
npm run dev
```

`npm test`로 계산을 검증할 수 있습니다. `npm run build` 후 `npm start`를 실행하면 빌드된 웹 앱이 [127.0.0.1:4174](http://127.0.0.1:4174)에서 제공됩니다. 변경 사항은 이 컴퓨터의 `.data/plan.json`에 저장됩니다.

## 계산 기준

- 분양가 **6억 2,950만원**에서 분양 계약금 **3,147만원**과 중도금 **3억 7,770만원**을 빼 분양 잔금 **2억 2,033만원**을 계산합니다. 원본 잔금과 1만원 차이가 있습니다.
- 초기 계획에서 기준일보다 앞선 직접 납부 항목을 납부 완료로 표시합니다. 납부 일정에서 상태를 수정할 수 있습니다. 옵션·확장은 일정에 적힌 납부액 기준으로 합산합니다.
- 중도금 이자는 실행일과 상환일 사이의 실제 경과 일수를 365일로 나누어 계산합니다. 각 회차의 금리는 6개월마다 갱신되고 입주일에 이자를 일괄 정산합니다.
- 입주 정산금은 중도금 잔여 원금과 아직 납부하지 않은 잔금·옵션·취득세·이자의 합입니다. 예상 주담대 필요액은 여기서 입주 시 가용자금을 차감한 값입니다. 입주 전 현금이 부족한 경우 별도로 표시합니다.
